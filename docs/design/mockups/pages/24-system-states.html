Rules

  • Every error keeps the Apolles header (or the agency brand on client pages) so the user is never stuck.
  • Errors during booking: never book twice. Check the booking status first and show "My bookings".
  • Error messages never show technical details or the supplier name. Log the details with the error code.
  • Client pages (quote links on the client domain): every error, including a server error, uses a client version with the agency brand when it is known, no Apolles and no agent buttons such as "My bookings".
  • Loading: use grey placeholder cards, not a blank page. Buttons show a spinner and stay disabled while working.
